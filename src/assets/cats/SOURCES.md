# 고양이 사진 출처 기록

이 폴더(`src/assets/cats/`)의 사진은 앱의 배경으로 쓰입니다. 사진마다 출처와 라이선스를 이 문서에 기록합니다.
이미지가 아닌 파일(.md)은 사진 목록에 잡히지 않으므로 이 문서는 빌드에 영향을 주지 않습니다.

## 사진 규격

- 확장자: `.webp` 권장 (`.jpg`·`.jpeg`·`.png`도 인식)
- 가로 1920px, 가로형 비율(3:2 ~ 16:9)
- 용량: 100~300KB 목표, 500KB 이하
- 새 파일 이름은 `cat-38`부터 사용 (삭제한 옛 사진 cat-01~37과 이름이 겹치지 않게)

1. 사진의 출처 페이지를 직접 열어 보았다.
